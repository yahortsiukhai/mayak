# 🌊 Маяк

Сервис мониторинга для малого бизнеса. Следит за сайтами, кассами и другими сервисами и присылает **понятные алерты в Telegram**.

## 💡 Идея

У малого бизнеса нет IT-специалиста. Когда сайт падает — узнают через 2 дня от злых клиентов. «Маяк» решает это: проверяет сервисы каждую минуту и говорит **человеческим языком**, что не так.

## 🎯 Целевая аудитория

- Кофейни, барбершопы, автосервисы, стоматологии
- Малые агентства (5-20 клиентских сайтов)
- Онлайн-школы и инфобиз
- Все, у кого есть сайт, но нет IT-специалиста

## 🛠️ Стек технологий

**Backend:**
- Python 3.13
- FastAPI — веб-фреймворк
- PostgreSQL — база данных
- Redis — кэш и очередь задач
- Celery — фоновые задачи (проверки сайтов)

**Frontend (позже):**
- HTMX + Tailwind CSS

**DevOps:**
- Docker + Docker Compose
- GitHub Actions (CI/CD)
- Prometheus + Grafana (мониторинг)
- Nginx (reverse proxy)

**Планируется:**
- Kubernetes (при росте)
- Terraform (IaC)
- Ansible (конфигурация)
